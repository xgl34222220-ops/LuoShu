# GPLv3 分发合规说明

本说明帮助第三方理解洛书的 `GPL-3.0-only` 分发要求，不构成法律意见，也不修改 `LICENSE`。

仅在自己设备上修改而不向他人提供副本，通常不产生向公众交付对应源代码的义务。只要把修改后的
模块 ZIP、APK 或其他可执行版本提供给他人，无论免费、收费、通过群聊还是下载站，都应同时做到：

1. 明确标注这是修改版本，并记录主要改动与日期；
2. 保留版权、GPLv3 许可证和第三方声明；
3. 向获得二进制的人提供该版本完整对应源代码，包括构建脚本和生成该二进制所需的修改；
4. 基于洛书形成的整体修改版本继续使用 GPLv3，不附加限制接收者依法复制、修改和再分发的条款；
5. 不暗示修改版本得到洛书作者背书，并自行确认所捆绑字体的授权范围。

单纯分享不含字体文件的配置 JSON/YAML，不会自动取得第三方字体的再分发权。字体许可证与洛书源码
许可证是两件独立的事，发布者必须分别确认。
