# 洛书 App UI V1.1 重构说明

本次界面重构以《统一软件 UI 设计规范 V1.1》和参考录屏为唯一视觉基准，业务逻辑、字体事务与 Root 执行链保持不变。

## 已落实

- MIUIX / Material 3 共用同一页面和语义 Token，不维护两套业务页面。
- 浅紫灰背景、大圆角分组卡片、四入口悬浮玻璃底栏。
- 首页改为状态仪表盘，突出当前字体、设备可信状态、任务状态和下一步操作。
- 字体库、字体工坊与设置页统一标题、边距、卡片层级和底栏避让。
- 任务中心由右侧 94% 宽圆角侧滑页打开，保留上一层空间关系。
- 集中管理 Monet、深色、纯黑、玻璃、底栏与高刷新率选项。
- 页面支持系统字体缩放、最小 48 dp 点击热区和稳定数字布局。

## 验收

- `scripts/font_library_ui_layout_test.sh` 验证页面骨架、Token、四入口底栏、侧滑页和关键布局约束。
- Android CI 负责 Kotlin 编译、App 构建、候选包和现有字体引擎回归测试。
