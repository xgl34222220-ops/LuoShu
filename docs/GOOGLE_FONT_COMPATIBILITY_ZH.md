# 洛书 Google 字体兼容使用说明

入口：**设置 → Google 字体兼容**。状态、按钮、确认弹窗和说明均为中文，不需要终端。

## 已经用过独立脚本

覆盖安装配套模块和 App，完整重启后打开本页。继续读取 `/data/adb/luoshu-google-font-fallback/user-<用户>.json` 的原恢复记录；身份和状态一致时显示「已开启 Google 字体兼容」，不用重复开启，也不用重新生成字体。

## 第一次使用

1. 先在洛书应用自定义字体，按提示完成重启。
2. 谷歌商店英文、数字仍反复恢复默认时，点击「开启 Google 字体兼容」，阅读影响并确认。
3. 显示已开启后完整重启手机，再检查商店，以及放后台重开后的效果。

「重新检测」不会开启或修改 Google 组件。点击「恢复原设置」会按记录恢复原来的 default 或显式启用状态，不统一强制启用。原本由其他工具停用而没有洛书记录的，不接管、不猜测。

## 已开启后又恢复默认

字体效果回退不一定代表组件开关被重置。Google 应用可能仍持有先前打开的字体文件或内存字体，也可能使用自己打包的字体；关闭再开启兼容会触发 Android 组件状态变化，相关 GMS 进程可能重建，因此暂时恢复不能证明具体原因。

洛书现在为已保存的合法恢复记录提供一次维护：模块启用且使用自定义字体、GMS 仍是同一安装、版本确实比最后核验时更新，并且原来是 default 的组件也回到了 default 时，可恢复之前已授权的兼容设置。组件仍停用时只记录已经核验的新版本，不反复切换。没有记录、同版本改动、明确启用的外部改动或重新安装的 GMS 均不会自动接管。

维护在现有开机/应用字体任务、返回洛书前台及能收到的 GMS 升级事件执行一次，不启动常驻监听或轮询。Android 可能推迟后台广播，洛书进程不存活时也不能即时接收；再次打开洛书会补做核验。

如果状态仍显示已开启但 Google 字体已经回退，可明确选择「重新应用兼容」。它保留开启前的原恢复记录，只重新应用当前用户的同一字体组件，失败时尝试回到本次操作前状态。无需先关闭再开启，也不清除字体缓存或应用数据。该操作可能重启相关 GMS 进程；完成后重新打开谷歌应用检查。它仍不能保证替换应用内置字体或网页指定字体。

## 恢复目录权限提示

若页面提示「洛书恢复根目录所有者或权限不安全」，表示恢复记录的共享目录检查未通过，尚未读取 Google 组件状态。某些 Root 入口会让洛书挂载辅助程序创建过宽的共享目录。修复版在重新检测时，仅对真实、Root 所有且位于可信父目录下的共享目录收紧组和其他用户的写权限，保留读与执行权限、挂载子目录及恢复记录。符号链接、其他所有者或不可信父目录仍会拒绝，不会自动改属主、递归改权限或删除记录。

恢复记录现保存在 `/data/adb/luoshu/google-font-fallback/user-<用户>.json`；旧独立脚本目录会在核验后迁移并保留兼容入口。无需重新生成字体。若使用修复版后仍提示权限异常，需要核对实际目录的属主、权限和类型；单凭此提示不能认定手机上的具体权限值。

## 影响与恢复

只停用当前 App 所属 Android 用户的 GMS FontsProvider 字体提供组件，不停用整个谷歌服务，不修改更新调度组件，不清除账户、App 数据或字体缓存。会影响该用户所有依赖 GMS 下载字体的应用，可能包括下载式表情字体；修改时相关 GMS 进程可能重启。

**停用或卸载模块前，先点击「恢复原设置」并完整重启。** 此设置跨重启保留；停用模块不保证自动恢复。卸载脚本会在删除运行环境前尝试恢复有记录的设置，失败记录仍保留；这不替代手动恢复。

**「默认卸载模块」保持关闭。** 安装、升级、开机和首次进入页面都不会自动开启此功能。不保证替换应用内置字体、网页指定字体或已打开的旧缓存。「已开启」只代表组件状态核验成功，不代表真机字体效果已验收。
